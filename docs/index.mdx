# Build iPix from the verified foundation

iPix is an AI-powered production platform for planning shoots, managing brands, coordinating talent, and delivering media.

This documentation explains what to keep from the proven product, what to rebuild, and how to ship the new system safely.

## Core architecture

The rebuild uses a clean Next.js foundation with CopilotKit and Mastra, while keeping proven iPix product logic and Supabase data contracts.

<Note>
The current production application stays independent until persistence, authorization, and tenant-isolation tests pass in preview.
</Note>
